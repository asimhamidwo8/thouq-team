# صفحة فريق ذوق / Thouq team page

موقع ثابت (GitHub Pages) بلغتين: العربي في الجذر `/` والإنجليزي تحت `/en/`.
السيرة الذاتية ملف PDF بالإنجليزي فقط.

## إضافة عضو
1. أضف كائن جديد في `team` داخل `team.json` (الأسماء والدور والموقع بالعربي والإنجليزي).
2. الحقول الفاضية (`phone` و`github`) ما تظهر. بدون `cv` ما يظهر زر السيرة.
3. `node build.js` ثم `python3 make_pdf.py` (لتوليد السيرة PDF).
4. صورة مربعة اختيارية: `photos/<slug>.jpg`.

## ملاحظات
- لا تضع رقم أحد أو إيميله بدون موافقته، الصفحة عامة.
- السيرة: عمود واحد، خط Arial، بدون صور (متوافقة مع أنظمة فرز السير ATS).
